# Evals

Gate 0 is trace fidelity: invocation captured, permission captured, result size measured, compaction boundary detectable, session identity preserved.

Primary: task success, wrong/missed/unnecessary rates, NONE quality, precision/coverage, arg validity, unauthorized-effect rate, time-to-first-action, latency, cost.

Context: schema/search/result tokens, cumulative AUC, cache hit/churn, D info-loss failures.

Kill: C needs ≥10pp success or ≥50% wrong+missed reduction vs B; D needs ≥30% context reduction or ≥5pp long-horizon gain; zero unauthorized effects.
